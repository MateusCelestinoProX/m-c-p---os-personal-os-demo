## ⚡ Visão Geral do Projeto

O **M.C.P Personal OS** é uma solução completa de sistema operacional pessoal voltada para produtividade de elite, foco profundo e gestão estratégica de metas, hábitos e conhecimento.

Esta **versão Demo** foi desenvolvida para portfólio profissional e demonstrações interativas:
- **Tela Base com Transição Cinematográfica**: Entrada suave com overlay hero executivo e carregamento em cascata com GSAP.
- **Privacidade Preservada & Mock Dataset de Alta Fidelidade**: Dados sensíveis e mídias privadas substituídos por um acervo curado de arquitetura, tecnologia e hábitos de alta performance.
- **Acesso Demonstração Imediato**: Sessão auto-autorizada com privilégios completos de administrador para exploração total da interface.

## 💎 Pilares Arquiteturais & Módulos

### 1. 🎨 Motor WebGL com 34 Shaders Reativos
- Biblioteca de shaders generativos em tempo real desenvolvidos em GLSL / OGL / Three.js (`Soft Aurora`, `Plasma Wave`, `Cyber Void`, `Hyperspace`, `Liquid Chrome`, `Silk`, `Beams`, `Ripple Grid`).
- Hardware throttling adaptativo (`getOptimizedDPR`) para sustentar 120 FPS em monitores ProMotion e economizar energia em dispositivos móveis.

### 2. 🎯 Habit Tracker & Heatmap Matrix
- Calendário de consistência cronológico com visualização de dias ativos e cálculo de streaks.
- Gráficos em Donut de 3 cores para visualização de tempo ativo, inativo e pausas.
- Modos adaptativos: Goal Mode (metas de 21, 40, 66, 90 e 365 dias) vs Cronológico contínuo.

### 3. 🗂️ Dreamboard & Galerias de Alta Estética
- Acervo visual distribuído em 6 galerias com layouts dinâmicos (Bento, Masonry, Showcase e Horizon):
  - *Architectural Brutalism & Spatial Geometry*
  - *Cybernetic Systems & Industrial Hardware*
  - *Nordic Minimalism & Spatial Light*
  - *Cosmic Horizons & Observatories*
  - *Editorial Vanguard & Spatial Typography*
  - *Hypercar Engineering & Precision Aerodynamics*

### 4. 🔒 Zero-Knowledge Cryptographic Vault (`diary.html`)
- Proteção criptográfica de notas e reflexões com algoritmo **AES-GCM 256-bit** no cliente usando a `WebCrypto API`.
- Chave mestra derivada localmente via PBKDF2 com salt e IV criptográficos únicos.

### 5. ⏱️ Control Engine & Pomodoro Flow
- Matriz unificada de tarefas e lembretes com prioridades.
- Cronômetro Pomodoro integrado com suporte a sessões de foco e pausas ativas.

## 🚀 Como Executar a Demo Localmente

```bash
# 1. Clonar o repositório
git clone https://github.com/MateusCelestinoProX/m-c-p---os-personal-os-demo.git
cd m-c-p---os-personal-os-demo

# 2. Iniciar servidor local estático
python3 -m http.server 5173
# ou
npx serve public/
```

Abra no navegador em:
- **Personal OS Principal (com intro cinematográfica)**: `http://localhost:5173/index.html`
- **Pure Calendar**: `http://localhost:5173/calendar.html`
- **Pomodoro Flow**: `http://localhost:5173/pomodoro.html`
- **Diário Criptografado**: `http://localhost:5173/diary.html`
- **Painel de Controle Admin**: `http://localhost:5173/admin.html`
